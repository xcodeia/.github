# XCODEIA

**XCODEIA** est un espace de conception et de développement de projets logiciels.

Nous développons et organisons des outils autour de la musique, des workflows DJ et des environnements de développement.

## Projets

| Projet | Description | Dépôt |
|---|---|---|
| **MIXXXCLOUD** | Cloud musical personnel, conçu pour une utilisation depuis le Web. | [xcodeia/MIXXXCLOUD](https://github.com/xcodeia/MIXXXCLOUD) |
| **CUE** | Projet d’outils DJ pour la préparation et la gestion de bibliothèques musicales. | [xcodeia/CUE](https://github.com/xcodeia/CUE) |
| **XCODEIA-DEVTOOLS** | Outils partagés pour le développement, les tests et la qualité des projets. | [xcodeia/XCODEIA-DEVTOOLS](https://github.com/xcodeia/XCODEIA-DEVTOOLS) |

## Organisation

Le dépôt [XCODEIA](https://github.com/xcodeia/XCODEIA) centralise la documentation et les informations de référence de l’organisation.

## Principes

- Développement structuré et documenté
- Séparation claire des projets et de leurs outils
- Tests et amélioration continue
- Accès aux dépôts selon leurs paramètres de visibilité et les autorisations accordées
